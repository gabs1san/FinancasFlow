# 💰 FinancasFlow

> Agente financeiro pessoal desenvolvido em .NET MAUI.

## 📌 Sobre o projeto

O FinancasFlow é um aplicativo de controle financeiro pessoal
que busca tornar o gerenciamento das finanças mais simples através
de uma experiência conversacional.

O usuário poderá informar seus gastos e entradas por texto ou áudio,
e o agente será responsável por interpretar, categorizar e registrar
essas informações.

## 🚀 Funcionalidades

- 💬 Chat com agente financeiro
- 💰 Registro de entradas
- 💸 Registro de gastos
- 🏷️ Categorização financeira
- 💳 Controle de cartão de crédito
- 📊 Resumo financeiro
- 👤 Perfil do usuário
- 🎤 Futuro suporte a comandos por voz
- 📑 Relatórios financeiros

## 🧠 Agente Financeiro

Exemplos:

> "Recebi R$ 2.000 de salário"

> "Gastei R$ 50 no mercado usando PIX"

> "Quanto sobrou do meu salário?"

> "Quanto vou pagar na próxima fatura?"
